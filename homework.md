## Git для новичков (часть 1)

- Git помогает сохранять историю изменений в проекте.
- Репозиторий — это папка с проектом, за изменениями которой следит Git.
- Коммит — это сохранённая версия изменений с описанием того, что мы сделали.
- Команда `git add` подготавливает файлы для следующего коммита.
- Команда `git commit` сохраняет подготовленные изменения в историю Git.
- GitHub позволяет хранить репозиторий в интернете и делиться им с другими людьми.
- Команда `git push` отправляет наши коммиты с компьютера на GitHub.

> 💬 **Заметка для ревьюера:** это мой первый Pull Request. Если видишь,
> как улучшить оформление файла — предложи правку через ревью.
> Например: сделать что-то жирным, добавить подзаголовок или список.
> Не стесняйся — это тренировка и для тебя, и для меня ;-)

## Git для новичков (часть 2)

- Когда над проектом работает несколько человек, каждый делает свою ветку, а потом все вместе вливают изменения в главную ветку `main`.
- Ветка — это как отдельная копия проекта, где можно спокойно работать, не мешая другим.
- Команда `git branch` показывает список всех веток.
- Команда `git checkout -b имя-ветки` создаёт новую ветку и сразу переключает на неё.
- Команда `git clone` скачивает полную копию чужого репозитория: файлы, историю и все ветки.
- Команда `git pull` забирает свежие изменения с GitHub и вливает их в мой проект.
- Команда `git merge` вливает одну ветку в другую.
- Если два человека меняли одно и то же место в файле, возникает конфликт — Git не может решить сам, и нужно выбрать вручную, что оставить.
- В команде в `main` напрямую не пушат — только через Pull Request и ревью.
